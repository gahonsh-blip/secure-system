## [1.0.0] - 2026-08-29

### Added
- Express.js static file server (`server.js`) with health check endpoint (`/api/health`) running on port 3000.
- Modern landing page (`index.html`) featuring:
  - Hero typing animation with Typed.js.
  - Interactive counter stats for completed projects and happy clients.
  - Mega dropdown menu for IT infrastructure & corporate security services.
  - 8-card services matrix with hover glow effect.
  - Project portfolio gallery with Unsplash imagery.
  - 5-step operational timeline.
  - Swiper 11 testimonial slider.
  - Interactive FAQ accordion.
  - Quote request form with direct email redirection.
  - Google Maps embed centered on Argora, Ranchi.
  - WhatsApp floating quick-action button.
- Dedicated regional pages in Hindi:
  - `about.html`: Detailed corporate overview and regional credibility metrics.
  - `services.html`: 6-card structured service catalog.
  - `contact.html`: Contact form, location details, QR code placeholder, and direct UPI payment handler (`upi://pay`).
- Custom styling (`style.css`):
  - Desktop custom cursor tracker with lag follower.
  - Floating keyframe animations.
  - Glassmorphism navigation bar.
  - Scroll progress indicator.
- Complete documentation suite:
  - `README.md`
  - `AGENTS.md`
  - `ARCHITECTURE.md`
  - `CONTRIBUTING.md`
  - `SECURITY.md`
  - `docs/SETUP.md`
  - `docs/API.md`
